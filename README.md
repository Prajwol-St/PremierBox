📽️ PremierBox – Movie Ticket Management System
🎯 Project Overview
PremierBox is a Java-based desktop application that simplifies movie ticket booking and management for small to mid-sized cinema halls. The system supports seat selection, movie and showtime management, and real-time booking feedback using a clean, GUI-based interface built with Java Swing.

🧠 Aim


To develop a user-friendly and efficient desktop application using Java Swing and MVC architecture that automates the process of movie ticket booking.

✅ Objectives
Design an intuitive GUI using Java Swing.

Implement the MVC design pattern.

Allow admins to manage movies and showtimes.

Let users view, select, and book available movie seats.

Visualize seat status (Available, Selected, Booked).

Handle data validation and errors efficiently.

🧩 Features
🔑 Admin Features
Add, update, or delete movies and showtimes.

View bookings and manage seats.

🎟️ User Features
Browse movies and showtimes.

Color-coded seat selection:

🟩 Available

🟨 Selected

🟥 Booked

Book tickets with real-time updates.

⚙️ System Features
Validations to prevent duplicate entries.

Dynamic seat status after booking.

Reusable and modular GUI components.

Error and exception handling.

🧱 Architecture
MVC Pattern

Model: Business logic and data handling (Movie, Showtime, Booking).

View: GUI screens (Login, Dashboard, Booking).

Controller: Handles user actions and communicates between Model and View.

📊 Development Methodology
Agile methodology using sprints and frequent iterations:

Sprint 1: Authentication (Login, Register, Reset)

Sprint 2: Admin movie management

Sprint 3: Booking system

Sprint 4: Integration and testing

Sprint 5: Documentation and final testing
